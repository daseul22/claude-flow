## ⚠️ 부분 구현 또는 미흡

### 🔴 피드백 루프 - **실제 작동 안함!** (가장 중요)

**현재 상태:**
- ✅ FeedbackLoop 클래스 있음
- ✅ 설정 모달에서 활성화/비활성화 가능
- ❌ **실제로 피드백 루프를 사용하는 코드 없음!**
- ❌ 조건 프롬프트 입력 UI 없음

**필요한 작업:**
```python
# app.py의 get_agent_response()에서:
if self.config.config.feedback_loop_defaults.enabled:
    # FeedbackLoop 사용
    async for chunk in self.feedback_loop.run_with_feedback(...):
        ...
else:
    # 일반 응답
    async for chunk in self.agent.send_message(...):
        ...
```

**누락된 UI:**
- 조건 프롬프트 입력 필드 (설정 모달에 추가 필요)
- 현재 반복 횟수 표시
- 피드백 결과 표시

---

### 🟡 cd 명령어 - 일부 기능 누락

**현재 구현:**
- ✅ cd [경로]
- ✅ cd ~
- ✅ cd ..
- ✅ 절대/상대 경로

**누락:**
- ❌ `cd -` (이전 디렉토리로 돌아가기)
- ❌ 디렉토리 히스토리 스택

**필요한 작업:**
```python
self.directory_history = []  # 디렉토리 히스토리

# cd - 처리
if path_str == "-":
    if self.directory_history:
        new_path = self.directory_history.pop()
```
