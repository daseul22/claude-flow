## 4. 세션 관리

### 4.1 명령어 실행 및 세션 자동 생성
**As a** 사용자
**I want to** 프로젝트 디렉토리에서 명령어로 TUI를 실행할 수 있다
**So that** 빠르게 프로젝트 컨텍스트에서 작업을 시작할 수 있다

#### 상세 기능
- 명령어 실행
  - `claude-flow` 명령어로 현재 디렉토리에서 실행
  - `claude-flow [경로]` 형태로 특정 디렉토리 지정 가능
  - 실행 위치를 자동으로 작업 디렉토리로 설정
- 프로젝트 자동 감지
  - 현재 디렉토리의 이름으로 프로젝트 식별
  - Git 저장소면 저장소 이름 사용
  - CLAUDE.md 파일 자동 로드
- 세션 자동 생성
  - `~/.claude-flow/{project-name}/sessions/` 경로에 세션 생성
  - 세션 ID: UUID v4
  - 세션 파일: `{session-id}.json`
- 메타데이터 기록
  - 프로젝트 경로
  - 생성 시간
  - 마지막 활동 시간
- 자동 저장
  - 메시지마다 실시간 저장
  - 세션 메타데이터 업데이트

#### 수락 조건
- [ ] `claude-flow` 명령어로 TUI를 실행할 수 있다
- [ ] 실행 위치가 자동으로 작업 디렉토리로 설정된다
- [ ] 프로젝트명이 자동으로 감지된다
- [ ] 세션이 `~/.claude-flow/{project-name}/sessions/`에 생성된다
- [ ] CLAUDE.md 파일이 있으면 자동으로 로드된다
- [ ] 세션이 실시간으로 자동 저장된다

---

### 4.2 세션 불러오기 및 이어가기
**As a** 사용자
**I want to** 이전 세션을 불러와서 대화를 이어갈 수 있다
**So that** 작업을 중단했다가 나중에 재개할 수 있다

#### 상세 기능
- 세션 목록 표시
  - 현재 프로젝트의 세션 목록 (`~/.claude-flow/{project-name}/sessions/`)
  - 최근 세션 우선 정렬
  - 세션 정보 표시 (생성 시간, 마지막 활동, 메시지 수, 토큰 사용량)
- 세션 선택 인터페이스
  - 화살표 키로 세션 탐색
  - 세션 미리보기 (첫 메시지 표시)
  - Enter로 세션 불러오기
- 세션 복원
  - 대화 기록 전체 로드
  - 컨텍스트 완전 복원
  - 세션 상태 복원 (설정, 모델 등)
- 새 세션 시작
  - 기존 세션 유지하면서 새 세션 생성
  - 단축키로 빠른 전환

#### 수락 조건
- [ ] 현재 프로젝트의 세션 목록을 볼 수 있다
- [ ] 세션을 선택해 불러올 수 있다
- [ ] 불러온 세션의 대화 기록이 완전히 복원된다
- [ ] 세션 간 빠르게 전환할 수 있다
- [ ] 새 세션을 시작할 수 있다

---

### 4.3 세션 관리 및 삭제
**As a** 사용자
**I want to** 세션을 검색하고 삭제할 수 있다
**So that** 불필요한 세션을 정리하고 디스크 공간을 확보할 수 있다

#### 상세 기능
- 세션 검색
  - 날짜 범위 필터
  - 키워드 검색 (메시지 내용)
  - 현재 프로젝트 기준 검색
- 세션 상세 정보
  - 전체 대화 기록 보기
  - 토큰 사용량 통계
  - 세션 메타데이터 확인
- 세션 삭제
  - 개별 세션 삭제
  - 날짜 기반 일괄 삭제 (예: 30일 이상 경과)
  - 삭제 전 확인 다이얼로그
  - 삭제 후 복구 불가 경고
- 세션 내보내기
  - JSON 형식으로 세션 백업
  - 다른 프로젝트로 세션 복사

#### 수락 조건
- [ ] 날짜와 키워드로 세션을 검색할 수 있다
- [ ] 세션의 상세 정보를 확인할 수 있다
- [ ] 세션을 개별적으로 삭제할 수 있다
- [ ] 오래된 세션을 일괄 삭제할 수 있다
- [ ] 세션을 JSON으로 내보낼 수 있다

### 5.2 작업 디렉토리 변경

#### 상세 기능

  - 프로젝트 루트 외부 이동 경고

  - 세션 내에서 방문한 디렉토리 기록

## 6. 로깅 및 모니터링

- [ ] 에러 발생 시 상세 정보가 로그에 기록된다
- [ ] 로그 파일이 일정 크기 이상이면 자동 압축된다

## 기술 스택

- **Rich**: 터미널 렌더링 및 마크다운 지원

### Backend
- **Claude Agent SDK**: AI 에이전트 실행
- **FastAPI** (선택): 백엔드 API (필요시)

### Storage
- **로컬 파일 시스템**: 세션, 로그, 설정 저장 (JSON)
- **SQLite** (선택): 세션 히스토리 (향후 고려)

### Language
- **Python 3.10+**: 메인 언어
