### 1. 설정 모달 입력 검증 ⭐

```python
# settings_modal.py
try:
    max_iter = int(self.query_one("#max-iterations", Input).value or "3")
    if not (1 <= max_iter <= 30):
        max_iter = 3
except ValueError:
    max_iter = 3
```
