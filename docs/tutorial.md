## 1. 환경 확인

설치가 제대로 되었는지 확인해봅시다.

### Step 1-1: Python 버전 확인

```bash
python3 --version
# 출력: Python 3.10.0 이상
```

3.10 미만이면 [README.md](../README.md#설치-가이드)의 설치 가이드를 참고하세요.

### Step 1-2: Claude Flow 설치 확인

```bash
which claude-flow-web
# 출력: /Users/.../.local/bin/claude-flow-web

claude-flow-web --version
# 출력: Claude Flow 4.0.0
```

설치되지 않았으면:

```bash
cd /path/to/claude-flow-web
./setup.sh
```

### Step 1-3: 환경변수 확인

```bash
echo $CLAUDE_CODE_OAUTH_TOKEN
# 출력: sk-proj-xxx... (공백이 아니어야 함)
```

비어있으면:

```bash
# 임시 설정
export CLAUDE_CODE_OAUTH_TOKEN='your-token-here'

# 또는 .env 파일 설정
echo "CLAUDE_CODE_OAUTH_TOKEN=your-token-here" > .env
```

## 2. Claude Flow 실행

### Step 2-1: 서버 시작

터미널에서 다음 명령어를 실행하세요:

```bash
claude-flow-web

# 출력 예시:
# ✓ FastAPI 서버 시작
# ✓ React 프론트엔드 로드
# ✓ 서버가 http://localhost:5173 에서 실행 중입니다
```

### Step 2-2: 웹 브라우저에서 접속

웹 브라우저를 열고 다음 URL에 접속하세요:

```
http://localhost:5173
```

```
│                                         │
│  ┌───────────────────────────────────┐ │
│  │                                   │ │
│  │      워크플로우 캔버스             │ │

│  │                                   │ │
│  └───────────────────────────────────┘ │
```

## 3. 첫 번째 워크플로우: 코드 분석

간단한 코드 분석 워크플로우를 만들어봅시다.

### Step 3-1: 워크플로우 생성

1. **"새 워크플로우" 버튼 클릭**
2. **워크플로우 이름** 입력: `"코드 분석 워크플로우"`
3. **생성** 클릭

### Step 3-2: Input 노드 추가

좌측 **노드 팔레트**에서 **"Input"** 노드를 캔버스에 드래그합니다.

```
[캔버스]
  ↓
[Input 노드 추가됨]
```

### Step 3-3: Input 노드 설정

Input 노드를 클릭하여 우측 패널을 엽니다:

```
설정 항목:
- 노드 이름: "코드 입력"
- 입력값: (비워 두기 - 실행 시 입력받음)
```

✅ **체크포인트**: Input 노드가 캔버스에 추가되었습니까?

### Step 3-4: Worker 노드 추가 (Code Reviewer)

좌측 **노드 팔레트**에서 **"Worker"** 노드를 캔버스에 드래그합니다.

```
[캔버스]
  ↓
[Input 노드]
[Worker 노드 추가됨]
```

### Step 3-5: Worker 노드 설정

Worker 노드를 클릭하여 우측 패널을 엽니다:

```
필수 설정:
- 노드 이름: "코드 리뷰"
- 에이전트: "code_reviewer" (드롭다운에서 선택)
- 작업 템플릿: "다음 코드의 문제점을 찾아주세요:

{{input}}"

허용 도구: read, grep, write (자동 선택됨)
```

설정을 확인하고 **저장** 버튼을 클릭합니다.

✅ **체크포인트**: Worker 노드가 설정되었습니까?

### Step 3-6: 노드 연결

Input 노드에서 Worker 노드로 연결선을 드래그합니다:

```
[Input 노드] ──→ [Worker 노드]
```

### Step 3-7: Output 노드 추가

좌측 **노드 팔레트**에서 **"Worker"** 노드를 추가로 드래그합니다 (최종 결과용).

```
Worker 노드 설정:
- 노드 이름: "결과 정리"
- 에이전트: "documenter"
- 작업 템플릿: "다음 코드 리뷰 결과를 요약해주세요:

{{node_2.output}}"
```

Worker 노드 → 이 노드로 연결선을 그립니다.

```
최종 워크플로우:
[Input] → [Code Reviewer] → [Documenter] → [Output]
```

✅ **체크포인트**: 3개의 노드가 연결되었습니까?

### Step 3-8: 워크플로우 검증

우측 상단의 **검증** 버튼을 클릭하여 워크플로우 문법을 확인합니다.

```
예상 출력:
✓ 워크플로우 검증 완료
✓ 순환 참조 없음
✓ 모든 노드 연결됨
```

### Step 3-9: 워크플로우 저장

**File** → **Save** (또는 Cmd+S) 를 클릭합니다.

```
저장 위치:
~/.claude-flow/workflows/코드_분석_워크플로우.json
```

✅ **체크포인트**: 워크플로우가 저장되었습니까?

## 4. 워크플로우 실행

### Step 4-1: 실행 준비

우측 상단의 **실행** 버튼을 클릭합니다.

```
[실행 준비 대화창]
┌─────────────────────────────────┐
│ 워크플로우 시작                  │
├─────────────────────────────────┤
│                                 │
│ 입력값을 입력하세요:            │
│                                 │
│ [테스트할 코드 입력...]         │
│                                 │
│ [예제: Python 코드]             │
│   def add(a, b):                │
│       return a + b              │
│                                 │
│   [실행] [취소]                 │
└─────────────────────────────────┘
```

### Step 4-2: 샘플 코드 입력

다음 코드를 입력 필드에 복사하세요:

```python
def calculate_average(numbers):
    sum = 0
    for num in numbers:
        sum = sum + numbers  # BUG: numbers[i] 아님
    return sum / len(numbers)
```

**특징**: 의도적으로 버그를 포함한 코드입니다.

### Step 4-3: 실행 시작

**[실행]** 버튼을 클릭합니다.

```
[실행 로그 패널]
┌─────────────────────────────────┐
│ 실행 중... (약 30초)            │
├─────────────────────────────────┤
│                                 │
│ ✓ node_1 (입력): 완료           │
│ ⏳ node_2 (코드 리뷰): 실행 중  │
│ ⏸ node_3 (결과 정리): 대기     │
│                                 │
│ [중단]                          │
└─────────────────────────────────┘
```

### Step 4-4: 실행 결과 확인

각 노드가 완료되면 실행 로그에서 결과를 확인할 수 있습니다.

**Node 2 (Code Reviewer) 결과:**

```
발견된 문제점:
1. 버그: sum = sum + numbers
   → 의도: sum = sum + numbers[i]
   이유: 리스트 전체를 숫자에 더함

2. 성능: 루프 사용 대신 sum() 함수 권장

3. 유형: 타입 힌트 추가 권장
   def calculate_average(numbers: List[int]) -> float:
```

**Node 3 (Documenter) 결과:**

```
## 코드 리뷰 요약

분석 대상: calculate_average() 함수

주요 문제:
- 런타임 에러 위험 (1건)
- 성능 개선 권장 (1건)

수정된 코드:
def calculate_average(numbers: List[int]) -> float:
    return sum(numbers) / len(numbers)
```

✅ **체크포인트**: 코드 리뷰 결과가 표시되었습니까?

### Step 4-5: 상세 로그 확인

실행 로그에서 **특정 노드를 클릭**하면 상세 로그를 볼 수 있습니다.

```
Node 2 (코드 리뷰) 상세:
- 입력: [샘플 코드]
- 출력: [리뷰 결과]
- 토큰 사용량: 850
- 소요 시간: 12초
```

### Step 4-6: 세션 저장

실행이 완료되면 자동으로 세션이 저장됩니다.

```
세션 정보:
- 세션 ID: sess-20240115-103045-abc123
- 프로젝트: claude-flow-web
- 워크플로우: 코드_분석_워크플로우
- 상태: 완료
- 토큰 사용량: 2,150

저장 위치:
~/.claude-flow/workflows/sessions/sess-20240115-103045-abc123.json
```

## 5. 고급: 병렬 테스트 워크플로우

이제 더 복잡한 워크플로우를 만들어봅시다.

### Step 5-1: 새 워크플로우 생성

1. **새 워크플로우** 생성
2. **이름**: `"병렬 테스트 워크플로우"`

### Step 5-2: 노드 구성

다음과 같은 구조를 만듭니다:

```
             ┌→ [Unit Tester] ┐
[Input Code] ┼→ [Integration Tester] ┼→ [Test Merger] → [결과]
             └→ [Performance Tester] ┘
```

### Step 5-3: 노드 추가 및 설정

**1) Input 노드**

```
- 이름: "테스트 코드"
- 입력값: (실행 시 입력받음)
```

**2) Worker 노드 (Unit Tester)**

```
- 이름: "단위 테스트"
- 에이전트: "unit_tester"
- 작업 템플릿: "다음 코드에 대해 단위 테스트를 작성하세요:

{{input}}"
```

**3) Worker 노드 (Integration Tester)**

```
- 이름: "통합 테스트"
- 에이전트: "integration_tester"
- 작업 템플릿: "다음 코드의 통합 테스트를 작성하세요:

{{input}}"
```

**4) Worker 노드 (Performance Tester)**

```
- 이름: "성능 테스트"
- 에이전트: "performance_tester"
- 작업 템플릿: "다음 코드의 성능을 분석하세요:

{{input}}"
```

**5) Merge 노드**

```
- 이름: "테스트 병합"
- 타입: "Merge"
- 병합 전략: "concatenate"
```

### Step 5-4: 연결선 설정

```
Input → Unit Tester ──┐
Input → Integration Tester ┼→ Merger → Output
Input → Performance Tester ┘
```

**중요**: 3개의 Tester 노드가 **모두 Input과 직접 연결**되어야 병렬 실행됩니다.

### Step 5-5: 워크플로우 실행

1. **검증** 클릭 (문법 확인)
2. **저장** 클릭
3. **실행** 클릭

### Step 5-6: 병렬 실행 모니터링

실행 로그에서 **병렬 실행**을 확인할 수 있습니다:

```
[라운드 1] (병렬)
✓ Unit Tester: 완료 (5초)
✓ Integration Tester: 완료 (8초)
✓ Performance Tester: 완료 (6초)

[라운드 2] (순차)
✓ Merger: 완료 (2초)

총 소요 시간: 10초
(순차 실행 시: 21초 - 약 50% 단축!)
```

✅ **체크포인트**: 3개의 Tester가 동시에 실행되었습니까?
