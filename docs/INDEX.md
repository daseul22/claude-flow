## 참고 자료

### 프로젝트 설정

| 파일 | 설명 |
|------|------|
| **[프로젝트 문서](../CLAUDE.md)** | 프로젝트 개요, 명령어, 아키텍처 개요 |
| **[설정 파일](../config/)** | agent_config.json, system_config.json |
| **.env** | 환경변수 (CLAUDE_CODE_OAUTH_TOKEN) |

### 기술 스택

| 기술 | 버전 | 용도 |
|------|------|------|
| **Python** | 3.10+ | 백엔드 |
| **FastAPI** | 0.109+ | REST API |
| **React** | 18 | 프론트엔드 |
| **PostgreSQL** | 13+ (향후) | 데이터베이스 |
| **Claude Agent SDK** | 최신 | AI 에이전트 |

### 주요 명령어

```bash
# 설치
./setup.sh                      # 자동 설치

# 개발
pip install -e .                # 개발 모드 설치
npm run dev                     # 프론트엔드 개발 (hot reload)
python -m src.presentation.web.app  # 백엔드 실행

# 포맷팅 & 린팅
black src/ --line-length 100    # 코드 포맷팅
ruff check src/                 # 코드 린팅
mypy src/                       # 타입 검사

# 빌드 & 배포
npm run build                   # 프론트엔드 빌드
claude-flow-web                 # 웹 UI 실행
```
