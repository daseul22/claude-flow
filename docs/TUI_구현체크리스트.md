## ❌ 누락된 핵심 기능

### 우선순위 1 (필수)
1. **툴 호출 표시** - 에이전트가 어떤 도구를 사용하는지 보여야 함
2. **설정 모달** - 기본 설정을 UI에서 변경할 수 있어야 함

### 우선순위 2 (중요)
3. **피드백 루프 UI** - 설정 파일이 아닌 UI에서 제어
4. **작업 디렉토리 변경** - cd 명령어 또는 UI

### 우선순위 3 (선택)
5. **로그 조회 UI**
6. **환경변수 편집 UI**

---

## 구현 계획

1. **툴 호출 표시 구현** ← 먼저 구현
2. **설정 모달 구현** ← 다음 구현
3. **피드백 루프 UI** (필요시)
4. **cd 명령어** (필요시)
