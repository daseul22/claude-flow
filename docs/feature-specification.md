# Claude Flow 기능명세서

> 사용자 관점 기능 중심 문서 (User Story 기반)

---

## 1. 프로젝트 관리

### 1.1 프로젝트 선택
- **As a user**, 프로젝트 디렉토리를 선택하여 워크플로우를 저장하고 관리할 수 있다
- **방법**: 디렉토리 브라우저 또는 경로 직접 입력
- **자동 복원**: 마지막 선택한 프로젝트 자동 로드

### 1.2 프로젝트 데이터 관리
- **세션 비우기**: 프로젝트의 모든 실행 세션 삭제 (용량 확보)
- **로그 비우기**: 모든 로그 파일 삭제
- **노드 세션 초기화**: 각 노드의 대화 기록 삭제

---

## 2. 워크플로우 설계

### 2.1 워크플로우 CRUD
- **생성**: 새 워크플로우 생성 (빈 워크플로우)
- **선택**: 드롭다운에서 워크플로우 선택 및 로드
- **저장**:
  - 자동 저장 (노드 추가/연결/설정 변경 시 5초 debounce)
  - 수동 저장 (Cmd/Ctrl+S 또는 상단 저장 버튼)
- **삭제**: 워크플로우 삭제
- **이름 변경**: 워크플로우 이름 수정

### 2.2 노드 추가 및 배치
- **드래그 앤 드롭**: 왼쪽 패널에서 노드를 캔버스로 드래그
- **클릭 추가**: 노드 버튼 클릭으로 자동 배치
- **노드 타입**:
  - **Input**: 워크플로우 시작점 (사용자 입력)
  - **Worker**: AI 에이전트 (범용/특화/커스텀)
  - **Condition**: 조건 분기 (True/False)
  - **Merge**: 여러 경로 병합

### 2.3 노드 연결
- **엣지 생성**: 노드 핸들을 드래그하여 연결
- **시각화**: 실행 중인 경로 강조 표시 (노란색)

### 2.4 노드 편집
- **복사/붙여넣기**: Ctrl+C / Ctrl+V (노드 복제)
- **삭제**: Delete 또는 Backspace 키
- **위치 조정**: 드래그로 노드 이동
- **자동 레이아웃**: "컴팩트" 버튼으로 자동 정렬

### 2.5 노드 설정
- **설정 패널**: 노드 선택 시 오른쪽 패널에서 상세 설정
  - **Worker 노드**:
    - 프롬프트 템플릿
    - 도구 권한 (read, write, bash 등)
    - 모델 선택 (Sonnet 4.5, Opus, Haiku)
    - Thinking 모드 (체크 시 AI의 내부 사고 과정을 로그에 표시)
  - **Input 노드**: 초기 입력값
  - **Condition 노드**: 조건 타입 (contains, equals, regex 등)
  - **Merge 노드**: 병합 전략 (concatenate, select_first 등)

## 3. 워커(Worker) 관리

### 3.1 범용 워커
- **Planner**: 요구사항 분석 및 계획 수립
- **Coder**: 코드 작성
- **Reviewer**: 코드 리뷰
- **Tester**: 테스트 실행
- **Committer**: Git 커밋 생성
- **Ideator**: 아이디어 생성
- **Product Manager**: 제품 관리
- **Documenter**: 문서 작성
- **Local**: 커스텀 워커 템플릿 (프롬프트 없음, 사용자가 직접 설정)

### 3.2 특화 워커
- **계획 특화**: feature_planner, refactoring_planner, bug_fix_planner, api_planner, database_planner
- **코드 작성 특화**: frontend_coder, backend_coder, test_coder, infrastructure_coder, database_coder
- **리뷰 특화**: style_reviewer, security_reviewer, architecture_reviewer
- **테스트 특화**: unit_tester, integration_tester, e2e_tester, performance_tester
- **기타**: bug_fixer, log_analyzer, summarizer

### 3.3 커스텀 워커 생성
- **AI 도움**: "새 워커 생성" 버튼으로 AI가 프롬프트 자동 생성
- **실시간 미리보기**: 생성 중 프롬프트 확인 가능
- **작업 재개**: 새로고침 시 진행 중인 워커 생성 자동 재개 (localStorage 기반)
- **프로젝트별 저장**: `.claude-flow/workers/` 디렉토리에 저장

## 4. 워크플로우 실행

### 4.1 실행 제어
- **시작**: 캔버스 우측 상단 "실행" 버튼
- **중지**: "실행 중지" 버튼 (실행 중일 때만 표시)
- **세션 재연결**: 새로고침 시 실행 중인 워크플로우 자동 재접속 (localStorage 기반)

### 4.2 실시간 모니터링
- **노드 상태 표시**:
  - 대기: 회색
  - 실행 중: 노란색 (회전 애니메이션)
  - 완료: 초록색
  - 에러: 빨간색
- **로그 스트리밍**: 실시간 로그 출력 (오른쪽 패널)
- **토큰 사용량**: 노드별 토큰 소비 표시

### 4.3 Human-in-the-Loop
- **워커 질문**: Worker가 사용자 입력을 요청하면 모달 팝업
- **답변 제출**: 사용자 답변을 Worker에게 전달

### 4.4 실행 로그
- **로그 필터링**: 노드별 로그 보기
- **상세 로그**: 개별 로그 클릭으로 상세 정보 확인
- **파싱된 출력**: 코드 블록, Artifact 등 구조화된 표시

## 5. 템플릿 및 자동화

### 5.1 템플릿 갤러리
- **내장 템플릿**: code_review, test_automation, bug_fix, ideation
- **템플릿 로드**: 클릭 한 번으로 워크플로우 적용
- **검색 및 필터링**: 카테고리별 템플릿 탐색

### 5.2 워크플로우 자동 설계
- **AI 설계**: "워크플로우 자동 설계" 버튼으로 요구사항 입력
- **자동 생성**: AI가 노드와 연결을 자동 생성
- **실시간 적용**: 설계 완료 시 캔버스에 즉시 반영
- **작업 재개**: 새로고침 시 진행 중인 설계 자동 재개 (localStorage 기반)

### 5.3 워크플로우 가져오기/내보내기
- **내보내기**: 워크플로우를 JSON 파일로 저장
- **가져오기**: JSON 파일에서 워크플로우 로드

## 6. 검증 및 디버깅

### 6.1 실시간 검증
- **자동 검증**: 워크플로우 변경 시 자동 검증 (1초 debounce)
- **오류 표시**:
  - **Error**: 빨간색 배지 (노드에 표시)
  - **Warning**: 노란색 배지
- **검증 패널**: 오른쪽 탭에서 모든 오류 목록 확인

### 6.2 검증 규칙
- **Input 노드 누락**: 워크플로우에 시작점이 없음
- **고아 노드**: 연결되지 않은 노드
- **순환 참조**: 무한 루프 방지
- **필수 필드 누락**: 노드 설정 미완료

---

## 7. 로그 및 세션 관리

### 7.1 로그 뷰어
- **파일 목록**: 프로젝트의 모든 로그 파일 목록
- **로그 내용**: 파일별 로그 내용 확인
- **자동 로드**: 실행 중인 워크플로우의 로그 자동 표시 (필터링 기능 지원)

### 7.2 세션 뷰어
- **세션 목록**: 프로젝트의 과거 실행 세션 목록 (완료/에러/취소)
- **세션 재생**: 클릭으로 과거 세션 내역 확인 (읽기 전용, 노드 상태 및 로그 포함)
- **세션 삭제**: 개별 세션 삭제

## 8. UI 및 설정

### 8.1 레이아웃
- **좌측 패널**: 노드 패널 (토글 가능)
- **중앙**: 워크플로우 캔버스
- **우측 패널**: 탭 형태 (노드 설정 / 실행 로그 / 검증)
- **상태 유지**: 패널 열림/닫힘 상태 자동 저장

### 8.2 키보드 단축키
- **Cmd/Ctrl+S**: 워크플로우 저장
- **Ctrl+C**: 노드 복사
- **Ctrl+V**: 노드 붙여넣기
- **Delete/Backspace**: 노드 삭제
- **Esc**: 노드 선택 해제 / 모달 닫기

### 8.3 알림
- **토스트**: 저장, 오류 등 주요 이벤트 알림
- **상태 표시**: 저장 상태 실시간 표시 (대기 중 / 저장 중 / 저장됨)

## 9. 미니맵 및 네비게이션

### 9.1 미니맵
- **전체 보기**: 워크플로우 전체 구조 한눈에 확인
- **노드 색상**: 상태별 색상 구분 (실행 중, 완료, 에러)
- **빠른 이동**: 미니맵 클릭으로 특정 영역 이동

### 9.2 캔버스 제어
- **확대/축소**: 컨트롤 패널 또는 마우스 휠
- **이동**: 드래그 또는 미니맵
- **그리드**: 16x16 스냅 그리드 (정렬 도움)

## 주요 워크플로우 예시

### 코드 리뷰 워크플로우
```
Input → Reviewer → Condition (승인?)
         ├─ True → Committer
         └─ False → Coder → Reviewer (재검토)
```

### 기능 개발 워크플로우
```
Input → Planner → Frontend Coder ┐
                → Backend Coder  ├─ Merge → Tester → Committer
```

### 버그 수정 워크플로우
```
Input → Bug Fixer → Unit Tester → Condition (통과?)
                      ├─ True → Committer
                      └─ False → Bug Fixer (재시도)
```

## 기술 제약사항

- **단일 세션**: 현재 하나의 워크플로우만 실행 가능 (동시 실행 불가)
- **세션 저장소**: 파일 기반 영속성 (~/.claude-flow/{project_name}/web-sessions/)
  - 서버 재시작 후에도 세션 기록 유지
  - 메모리 캐싱으로 빠른 접근 제공
- **프론트엔드 빌드**: 프로덕션 실행 시 `npm run build` 필수
